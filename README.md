# Phase 1 Battery Recycling Line

Engineering-blueprint model and energy/utility baseline for the Whalefall mechanical end-of-life battery recycling line (Lishui reference plant), with an international 1 t/h black-mass module variant.

## Contents

- `energy-model/lishui-energy-baseline.json` — line-level energy, utility and waste baseline with field actuals (dry line 12.6 GWh/a on 50 kt/a feed; wet line 100 GWh/a + 112 kt/a steam) and flagged placeholders (N2 inerting, PPA tariff, NG).

## Settled design decisions (2026-11)

- **Pre-treatment:** nitrogen-inerted shredding of charged packs — no discharge (放电) station.
- **Tail gas:** secondary combustion chamber (二燃室) + quench + alkali scrubbing; RTO not used on this stream.
- **Compliance:** GB 31573-2015 and HJ 1186-2021; wastewater pretreated on-site, discharged to municipal sewer.
